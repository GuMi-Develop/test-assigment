## Запуск и установка проекта

### Установка:

```bash
git clone *ссылка  на проект*
```

### Запуск:

```bash
# Создание виртуального окружения
python3 -m venv venv

# Активация виртуального окружения (Linux)
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера
python -m http.server 8000

# В другом терминале запуск тестов
pytest tests/ -v
```

## Баги, которые найдены при тестировании проекта

- Номер карты может содержать более 16 цифр (Critical)
- Возможен перевод отрицательной суммы (Critical)
- Некорректное отображение комиссии при вводе отрицательных значений (Medium)
- Номер карты не сбрасывается при смене счёта (Medium)
- Возможен перевод нулевой суммы (High)
