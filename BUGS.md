# Баг-репорты

## БАГ №1: Некорректная валидация длины номера карты

| Поле                      | Значение                                                                                                                                                                             |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Заголовок**             | Номер карты может содержать более 16 цифр                                                                                                                                            |
| **Приоритет**             | High                                                                                                                                                                                 |
| **Серьёзность**           | Critical                                                                                                                                                                             |
| **Окружение**             | localhost:8000, браузер Chrome                                                                                                                                                       |
| **Предусловие**           | - Сервис запущен с параметрами http://localhost:8000/?balance=30000&reserved=20001<br>- Открыта страница банка                                                                       |
| **Шаги воспроизведения**  | 1. Нажать на карточку "Рубли"<br>2. В поле "Номер карты" ввести 17 цифр: `1111 2222 3333 4444 5`<br>3. В поле "Сумма перевода" ввести любую сумму<br>4. Нажать на кнопку «Перевести» |
| **Ожидаемый результат**   | Сообщение об ошибке: «Номер карты должен содержать ровно 16 цифр»                                                                                                                    |
| **Фактический результат** | Ввод принимается, перевод выполняется                                                                                                                                                |
| **Дополнительно**         | По инструкции: «номер карты, состоящий из ровно 16 цифр»                                                                                                                             |

## БАГ №2: Возможен перевод отрицательной суммы

| Поле                      | Значение                                                                                                                                                                                            |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Заголовок**             | Поле суммы принимает отрицательные значения, перевод выполняется                                                                                                                                    |
| **Приоритет**             | High                                                                                                                                                                                                |
| **Серьёзность**           | Critical                                                                                                                                                                                            |
| **Окружение**             | localhost:8000, браузер Chrome                                                                                                                                                                      |
| **Предусловие**           | - Сервис запущен с параметрами http://localhost:8000/?balance=30000&reserved=20001<br>- Открыта страница банка                                                                                      |
| **Шаги воспроизведения**  | 1. Нажать на карточку "Рубли"<br>2. В поле "Номер карты" ввести 16 цифр: `1111 2222 3333 4444`<br>3. В поле "Сумма перевода" ввести отрицательное число: `-1000`<br>4. Нажать на кнопку "Перевести" |
| **Ожидаемый результат**   | Ошибка: «Сумма перевода должна быть положительной»                                                                                                                                                  |
| **Фактический результат** | - Ввод принимается<br> - Комиссия рассчитывается как -100₽<br>- Перевод выполняется                                                                                                                 |

## БАГ №3: Некорректное отображение комиссии при вводе отрицательных значений

| Поле                      | Значение                                                                                                                                                                                             |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Заголовок**             | Некорректное отображение комиссии при вводе отрицательных значений                                                                                                                                   |
| **Приоритет**             | Medium                                                                                                                                                                                               |
| **Серьёзность**           | Medium                                                                                                                                                                                               |
| **Окружение**             | localhost:8000, браузер Chrome                                                                                                                                                                       |
| **Предусловие**           | - Сервис запущен с параметрами http://localhost:8000/?balance=30000&reserved=20001<br>- Открыта страница банка                                                                                       |
| **Шаги воспроизведения**  | 1. Нажать на карточку "Рубли"<br>2. В поле "Номер карты" ввести 16 цифр: `1111 2222 3333 4444`<br>3. В поле "Сумма перевода" ввести отрицательное число: `-500`<br>4. Проверить отображение комиссии |
| **Ожидаемый результат**   | - Комиссия должна быть 0 или положительным числом<br>- Комиссия должна рассчитываться от модуля числа или отбрасывать отрицательный знак                                                             |
| **Фактический результат** | Комиссия отображается как отрицательное число: `-50₽`                                                                                                                                                |
| **Дополнительно**         | В сочетании с багом №2 (возможность перевода отрицательной суммы) создает путаницу для пользователя                                                                                                  |

## БАГ №4: Номер карты не сбрасывается при смене счёта

| Поле                      | Значение                                                                                                                                                             |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Заголовок**             | Номер карты не сбрасывается при смене счёта                                                                                                                          |
| **Приоритет**             | Medium                                                                                                                                                               |
| **Серьёзность**           | Medium                                                                                                                                                               |
| **Окружение**             | localhost:8000, браузер Chrome                                                                                                                                       |
| **Предусловие**           | - Сервис запущен с параметрами http://localhost:8000/?balance=30000&reserved=20001<br>- Открыта страница банка                                                       |
| **Шаги воспроизведения**  | 1. Нажать на карточку "Рубли"<br>2. В поле "Номер карты" ввести 16 цифр: `1111 2222 3333 4444`<br>3. Нажать на карточку "Доллары"<br>4. Проверить поле "Номер карты" |
| **Ожидаемый результат**   | - При переключении на другой счет поле "Номер карты" должно очищаться<br>- Пользователь должен вводить номер карты заново для каждого перевода                       |
| **Фактический результат** | - Номер карты сохраняется при переключении на другой счет<br>- В поле "Номер карты" по-прежнему отображается `1111 2222 3333 4444`                                   |
| **Дополнительно**         | Баг может привести к отправке денег на неверную карту                                                                                                                |

## БАГ №5: Возможен перевод нулевой суммы

| Поле                      | Значение                                                                                                                                                                             |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Заголовок**             | Возможен перевод нулевой суммы                                                                                                                                                       |
| **Приоритет**             | High                                                                                                                                                                                 |
| **Серьёзность**           | High                                                                                                                                                                                 |
| **Окружение**             | localhost:8000, браузер Chrome                                                                                                                                                       |
| **Предусловие**           | - Сервис запущен с параметрами http://localhost:8000/?balance=30000&reserved=20001<br>- Открыта страница банка                                                                       |
| **Шаги воспроизведения**  | 1. Нажать на карточку "Рубли"<br>2. В поле "Номер карты" ввести 16 цифр: `1111 2222 3333 4444`<br>3. В поле "Сумма перевода" ввести `0`<br>4. Проверить состояние кнопки "Перевести" |
| **Ожидаемый результат**   | - Перевод нулевой суммы должен быть невозможен<br>- Кнопка "Перевести" должна быть неактивна или отсутствовать<br>- Должно появляться сообщение об ошибке валидации                  |
| **Фактический результат** | - Кнопка "Перевести" активна при сумме `0`<br>- Комиссия отображается как `0₽`<br>- Перевод нулевой суммы технически возможен                                                        |
| **Дополнительно**         | - Хотя это не критично, но нарушает бизнес-логику<br>- Может ввести пользователя в заблуждение                                                                                       |
